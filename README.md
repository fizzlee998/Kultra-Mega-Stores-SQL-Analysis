Kultra Mega Stores (KMS) SQL Data Analysis
Overview

This project presents a detailed SQL-based analysis of Kultra Mega Stores’ sales, customers, products, and shipping data. The goal is to extract actionable insights to support business decisions, optimize revenue, and improve operational efficiency.

Key Insights

Top Product Category: Identified the product category with the highest sales.

Regional Performance: Highlighted the top 3 and bottom 3 regions by sales.

Appliance Sales in Ontario: Calculated total sales.

Customer Analysis:

Determined the most valuable customers, including small business clients.

Identified the most profitable consumer customer.

Analyzed revenue potential from the bottom 10 customers.

Shipping Costs: Found the shipping method with the highest cost and analyzed shipping efficiency based on order priority.

Order Trends: Evaluated corporate orders between 2009–2012 and purchasing patterns of high-value customers.

Files Included

kmsss.sql – SQL dump of the KMS database.

queries.sql – SQL scripts used for the analysis.

README.md – Project overview and instructions.

How to Use

Import the kmsss.sql file into your MySQL database.

Run the queries in queries.sql to reproduce the analysis.

Explore the dataset for additional insights or reporting purposes.

Recommendations for Management

Focus on bottom-performing customers with targeted promotions.

Optimize shipping methods based on cost and order priority.

Leverage insights from high-value customers to enhance product offerings.

Allocate resources effectively to improve underperforming regions.
